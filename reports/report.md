# Report: does pathology-report text add survival-ranking information in TCGA-BRCA?

All numbers below come from `results/dev_cv.json`, `results/test_results.json`, `results/leakage_scan.json`, `results/text_embedding.json` and `data/manifest.json`. The tables under "Full tables" are generated by `scripts/render_tables.py`.

## Answer

**No detectable gain.** The prespecified primary analysis used Cox PH on the PFI endpoint, evaluated once on a held-out test set (n=255, 35 events). A frozen BiomedBERT embedding of the diagnostic pathology report did not improve ranking:

- Over clinical covariates: C(clinical+text) − C(clinical) = **−0.010, 95% CI [−0.078, 0.065]**.
- Over clinical+RNA: C(clinical+RNA+text) − C(clinical+RNA) = **+0.000 [−0.040, 0.042]**.

Under the decision rule fixed in `docs/protocol.md` before testing, this is reported as *no detectable gain in this cohort*. The intervals are wide, so a modest benefit of a few C-index points cannot be ruled out either.

## Supporting observations

**Text alone carries some prognostic signal, but less than four clinical variables.**
- Text-only Cox, PFI: test C = 0.601 [0.499, 0.699]; development CV 0.601 ± 0.050.
- Clinical-only Cox: test 0.736; development CV 0.682.
- So the report embedding is not empty. In this design, though, what it captures appears to be already covered by age, stage and histology. Pathologic stage is itself derived from pathology findings.

**RNA also did not add on test.**
- Clinical+RNA − clinical on test: −0.003 [−0.083, 0.074].
- In development CV, RNA looked helpful for PFI (Δ +0.039 ± 0.055, positive in 10/15 folds), but that did not replicate on test.
- This shows how unstable C-index differences are with about 21 events per CV fold and 35 test events.

**Secondary network family: the apparent text gain is not trustworthy.** The late-fusion network does show positive text contrasts on PFI:
- Clinical+text − clinical: +0.073 [0.001, 0.138].
- Clinical+RNA+text − clinical+RNA: +0.081 [0.042, 0.125].

We do **not** read these as evidence that text helps:
1. **The network's clinical-only reference is degenerate** (C = 0.634, versus 0.736 for the clinical Cox model). In 2 of 5 seeds (11 and 23), early stopping restored the epoch-0 weights because inner-validation loss never improved. Per-seed test C for that reference ranged from 0.487 to 0.756. The positive Δ mainly measures how badly the reference underfits.
2. **The best text-including network still does not beat the simple baseline.** Clinical+RNA+text scored C = 0.725, which does not exceed the prespecified clinical-only Cox at 0.736. This is a descriptive comparison, not a prespecified one.
3. **These are secondary contrasts among many** (6 feature sets × 2 families × 2 endpoints), with no multiplicity correction.

This network weakness was already visible in development CV, where the network's clinical-only C was 0.614 against 0.682 for Cox (`results/dev_cv.json`, committed before the freeze). The prespecified network was kept rather than retuned on development results. Only after the test run was the mechanism diagnosed: early stopping restoring the epoch-0 weights. Per-run diagnostics were saved only for the test phase, so how often this happened during development is unknown. A future version should use a minimum epoch count or a linear skip path.

**OS (secondary endpoint).** Neither interval excludes 0:
- Cox clinical+text − clinical: +0.022 [−0.039, 0.084].
- Cox clinical+RNA+text − clinical+RNA: +0.022 [−0.027, 0.073].

**Leakage sensitivity.** We removed the 41 test patients whose reports mention recurrence-score assays, recurrent or prior breast cancer, neoadjuvant or post-treatment change, death/autopsy, or relapse/progression. That leaves n=214 with 31 PFI events. The Cox text contrast becomes −0.004 [−0.078, 0.082], so the conclusion is unchanged.

**Site confound.**
- On the development set, logistic regression on the 16 text principal components identifies the tissue source site with **0.893 accuracy** (13 sites; majority baseline 0.173). The embeddings therefore strongly encode the tissue source site. A plausible, untested explanation for their small added value is that much of their variance reflects institution and formatting rather than pathology content.
- A site-only Cox model ranks PFI at C = 0.471 ± 0.055 in development CV. Site alone is therefore not a strong shortcut here, so the text result is unlikely to be inflated by site.

## What this does and does not show

It **shows** that:
- The three public TCGA sources can be joined at patient level: N = 1018 with all three modalities.
- Long OCR'd reports can be encoded reproducibly on CPU with a frozen transformer. 623 of 1018 reports needed more than one 512-token chunk.
- A text modality can be evaluated against strong simple baselines, with patient-level splits, training-only preprocessing and a one-shot test.
- A null result can be reported as such.

It does **not** show that:
- Pathology text is useless. A fine-tuned or section-aware encoder, structured extraction (receptor status, node counts), or a larger cohort might behave differently. None of these were tested.
- Any model here is clinically valid or calibrated. This is a single retrospective cohort with no external validation, and C-index measures ranking only.
- RNA lacks prognostic value in breast cancer. Here, an unsupervised PCA of 5000 high-variance genes did not add to clinical variables on this test split.
